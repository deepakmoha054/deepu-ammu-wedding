## ⚙️ Setup — RSVP (Web3Forms)

1. Go to [web3forms.com](https://web3forms.com)
2. Enter your email and click **Create Access Key**
3. In each HTML file, find `YOUR_WEB3FORMS_ACCESS_KEY_HERE` and replace with your key
4. Every RSVP will be emailed to you instantly

## ⚙️ Setup — RSVP to Google Sheets (optional)

See `rsvp-google-sheet-script.js` for full step-by-step instructions.

## ✏️ Customisation

All colours are defined as CSS variables in `:root{}` at the top of each file.  
All text content (names, dates, venues, story) is clearly commented in the HTML.  
To add couple photos: open any page in a browser and tap the photo placeholder areas.
